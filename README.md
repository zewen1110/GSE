GSE
**Project Overview
**
This repository contains the codes and raw data associated with the article:
“Integrative Multi-Omics, Machine Learning, and Molecular Simulations Drive the Discovery of Grape Seed and Its Key Compounds for Diabetic Nephropathy.”
The project integrates multi-omics analysis, machine learning modeling, and molecular simulations to systematically uncover the potential mechanisms of grape seed and its key compounds in the treatment of diabetic nephropathy.
Repository Contents
The project is organized into the following components:
Raw Data
Transcriptomic datasets from GEO (GSE96804)
Grape seed compounds and target databases
Data related to immune infiltration and cell–cell interaction analyses
Data Preprocessing & Differential Expression Analysis (DEG)
Differentially expressed gene (DEG) results
Weighted Gene Co-expression Network Analysis (WGCNA)

Multiple algorithms for hub gene selection (LASSO, Random Forest, SVM, XGBoost)

Enrichment and Single-Gene Analyses

code of Molecular Dynamics (MD) Simulations

Immune infiltration profiling

Usage
Environment: Python (≥3.9), R (≥4.2); GPU acceleration (CUDA) recommended for certain modules.
Dependencies: Refer to requirements.txt and R_packages.txt.
